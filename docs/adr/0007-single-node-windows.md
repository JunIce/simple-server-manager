# ADR-007: 单机 Windows 优先，不做分布式

## 状态
已接受

## 背景
需要明确系统的部署边界与目标平台。是否引入多主机联邦管理、是否支持多平台。

## 决策
- **单机部署**：不引入分布式 agent / 多主机联邦管理。
- **Windows 优先**：优先实现 Windows 平台的运维功能，接口层通过 `Platform` 抽象预留跨平台扩展能力。

## 备选方案

| 方案 | 优点 | 缺点 | 为何不选 |
|------|------|------|---------|
| 单机 | 简单、可靠、无网络复杂度 | 不支持跨主机 | **选中** |
| 主控 + agent 联邦 | 跨主机统一管理 | 网络、鉴权、心跳复杂度高 | 超出当前需求，YAGNI |
| 三平台同等支持 | 覆盖广 | 平台差异投入大 | 当前仅 Windows 运维场景 |

## 影响
- 正面：聚焦 Windows 运维痛点，交付快、可靠性高。
- 负面：暂不支持跨主机统一管理。
- 配套：`internal/platform` 接口保持抽象，未来可扩展 Linux/macOS 或 agent 模式。

## 风险与缓解
- 需求扩展到多主机 → Platform 抽象 + API 层已预留扩展点。
