# ADR-006: 配置以 JSON 文件持久化，不引入数据库

## 状态
已接受

## 背景
需要持久化服务配置与运行状态。候选：SQLite、内嵌 KV（bbolt）、JSON 文件。

## 决策
采用 **JSON 文件** 持久化到本地或系统用户目录，**不依赖任何数据库**。

## 备选方案

| 方案 | 优点 | 缺点 | 为何不选 |
|------|------|------|---------|
| SQLite | 查询强 | 引入 CGO 或外部依赖 | 场景简单无需关系型查询 |
| bbolt（内嵌 KV） | 事务、纯 Go | 二进制格式、不便人工查看 | 配置量小、需可读 |
| JSON 文件 | 可读、零依赖、易备份迁移 | 无并发事务 | **选中** |

## 影响
- 正面：零依赖、配置可读可审计、便于备份/迁移。
- 负面：无事务，需自行保证写入原子性。
- 配套：
  - 存储位置：`--config` 参数 > `%LOCALAPPDATA%\service-manager\config.json` > 当前目录 `config.json`。
  - 原子写：临时文件 + `os.Rename`。
  - 运行期用 `sync.RWMutex` 保护读写。

## 风险与缓解
- 写入中途崩溃损坏文件 → 临时文件 + rename 原子替换。
